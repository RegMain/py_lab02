# Лабораторная работа №2

**Задача**: написать CLI утилиту анализа логов в формате CSV или JSON Lines

**Функционал**:
- Построчное чтение входных файлов
- Поддержка CSV с заголовком и JSONL
- Вывод общего числа событий и файлов
- Вывод числа событий каждого уровня
- Вывод числа событий каждого источника
- Вывод ТОП 5 ошибок уровня ERROR/CRITICAL
- Нахождение первой и последней временной метки
- Формирование отчёта в консоли
- Формирование отчёта в JSON и CSV (по необходимости)
- Поддержка различных кодировок JSON и CSV файлов

**Принцип работы**:
Создаётся парсер-генератор для каждого входного файла, который генерирует события (event) для анализатора. Он, в свою очередь, передаёт сведения в отчёт.

**Инструкция**: запуск (из виртуального окружения):
`python -m streamstats`
При запуске без аргументов программа выдаст справку об использовании (`--help`)

Использование:
```bash
python -m streamstats analyze [-h] --format FORMAT [--json-report JSON_REPORT] [--csv-report CSV_REPORT] [--encoding ENCODING] [--skip-invalid] [--header] input [input ...]
```

Обязательный флаг `--format` позволяет указать формат входных файлов.\
Флаги `--json-report` и `--csv-report` позволяют, соответственно, создать отчёт в формате JSONL и CSV (необходимо указать имя файла).\
Флаг `--encoding` задаёт кодировку входных данных. По умолчанию это UTF-8.
Флаг `--skip-invalid` при указании создаёт файл warnings.log и записывает ошибки исполнения туда, вместо остановки работы программы (режим по умолчанию).\
Флаг `--header` (для формата CSV) при указании считывает первую строку каждого файла, как заголовок, и использует её для дальнейшей работы с полями.\
Далее вы можете указать сколько угодно своих файлов.
